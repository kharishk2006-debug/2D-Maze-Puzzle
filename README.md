# 🎮 2D Maze Puzzle Game

A 2D maze puzzle game prototype developed using **Unity and C#**, focusing on player movement, collision systems, interactive gameplay, and basic level design.

This project was developed as a hands-on game development prototype to practice core Unity gameplay mechanics and create a playable puzzle experience.

---

## 🕹️ Gameplay

The player navigates through a maze while avoiding walls and obstacles to reach the destination.

The project focuses on implementing fundamental game development concepts such as:

* Player movement
* Maze navigation
* Collision detection
* Interactive gameplay
* Basic level design
* Unity Physics
* Game testing and debugging

---

## ✨ Features

* 🎮 Player movement system
* 🧩 Maze-based puzzle gameplay
* 💥 Collision detection
* 🗺️ Maze level design
* ⚙️ Unity Physics implementation
* 🎯 Goal-based gameplay

## ▶️ How to Run

### 💻 Run in Unity Editor

1. Clone this repository.
2. Open **Unity Hub**.
3. Select **Add → Add project from disk**.
4. Select the cloned project folder.
5. Open the project using the compatible Unity version.
6. Open the game scene from the `Assets/Scenes` folder.
7. Click **Play** in the Unity Editor.
